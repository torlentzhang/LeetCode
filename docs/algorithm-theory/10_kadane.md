# 最大子数组和 / Kadane 算法 (Maximum Subarray)

## 核心思想
定义状态 **`cur` = “以当前元素结尾”的连续子数组的最大和**。走到第 `i` 个元素时只有两个选择：

- **接上前面**：`cur + nums[i]`
- **从自己重新开始**：`nums[i]`

取较大者：`cur = max(cur + nums[i], nums[i])`，同时用 `maxSum` 记录历史最优。

关键推导：`nums[i] > cur + nums[i]` ⟺ `cur < 0`。也就是说，**只有前面累积的和为负时，它才会拖累后面，这时才舍弃前面**。这是“贪心地在每一步作出局部最优选择”的典型结构，本质是动态规划的状态压缩（只保留上一步的最优解）。

## 适用场景（题目关键词）
1. “**连续**子数组 / 子串” + “**最大 / 最小和**” → 优先想 Kadane
2. 一维数组上的“以 i 结尾”状态可以压缩成单个变量的问题
3. 变形：最大乘积子数组（需同时维护 max 与 min，因为负负得正）
4. 变形：环形数组最大子数组（`max(不跨越边界的最大和, 总和 - 最小子数组和)`）
5. 变形：需要返回子数组本身（额外记录起点、临时起点）

## 模板代码
```typescript
function maxSubArray(nums: number[]): number {
  let cur = nums[0];        // 以当前元素结尾的最大和
  let maxSum = nums[0];     // 历史最优，初值必须是 nums[0]

  for (let i = 1; i < nums.length; i++) {
    cur = Math.max(cur + nums[i], nums[i]);   // 接上 or 重新开始
    maxSum = Math.max(maxSum, cur);
  }
  return maxSum;
}
```
时间 O(n)，空间 O(1)。

## 示例：模拟执行
`[5, -10, 8]`

| i | nums[i] | 接上前面 | 从自己开始 | cur | maxSum |
|---|---|---|---|---|---|
| 0 | 5 | — | — | 5 | 5 |
| 1 | -10 | -5 | -10 | -5 | 5 |
| 2 | 8 | 3 | 8 | 8 | **8** |

`cur = -5 < 0`，所以在 `8` 处“从自己开始”胜出，答案 8。

## 与滑动窗口的区别
这题**不是**滑动窗口：
- 滑窗需要“窗口越长越差”或“满足单调性”的收缩条件
- 这题里“窗口和小于历史最大值”并不能推出“该丢掉左边哪一个”，收缩条件不成立
- Kadane 的收缩是**语义明确的**：只要“以 i 结尾的最优和”为负，就整段丢弃，从当前元素重新开始

## 易错点
- **初值不能是 0**：全负数数组（如 `[-3, -1, -2]`）会错误返回 `0`，正确答案是最大的那个负数 `-1`
- 循环从 `i = 1` 开始，`i = 0` 已被初值覆盖
- `cur` 允许为负，它是“以 i 结尾”的局部最优，不等于全局最优；全局最优靠 `maxSum` 单独记录
- 若题目要求子数组不能为空，不要额外引入 `Math.max(0, ...)`，否则又回到“空数组”陷阱

## 关键要点
- 状态定义抓“**以 i 结尾**”，才能把“连续”这个约束变成可递推的
- 本质是“**接上 or 重开**”的两选一，判断依据是前面的累积和是否为负
- 看到“连续子数组 + 最大和”就该条件反射想到这个 O(n)/O(1) 模板
