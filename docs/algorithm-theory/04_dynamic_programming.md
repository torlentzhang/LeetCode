# 动态规划 (Dynamic Programming)

## 核心思想
将复杂问题分解为**重叠子问题**，通过保存子问题的解来避免重复计算。

## 适用场景
1. **求最优解**（最大值、最小值、最长、最短）
2. **计数问题**（有多少种方案）
3. **存在性问题**（是否可行）

## 解题步骤
1. **定义状态**：dp[i] 表示什么含义？
2. **状态转移方程**：dp[i] 如何从之前的状态推导出来？
3. **初始化**：基础情况是什么？
4. **计算顺序**：从小到大还是从大到小？

## 基本模板
```typescript
function dp(n: number): number {
  // 1. 定义状态数组
  const dp = new Array(n + 1).fill(0);
  
  // 2. 初始化基础情况
  dp[0] = 0;
  dp[1] = 1;
  
  // 3. 状态转移
  for (let i = 2; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];  // 示例：斐波那契
  }
  
  return dp[n];
}
```

## 经典题型
1. **斐波那契数列**：dp[i] = dp[i-1] + dp[i-2]
2. **爬楼梯**：dp[i] = dp[i-1] + dp[i-2]
3. **最长递增子序列**：dp[i] = max(dp[j] + 1) for j < i
4. **背包问题**：dp[i][w] = max(dp[i-1][w], dp[i-1][w-weight] + value)

## 关键要点
- **重叠子问题**：同一个子问题会被多次计算
- **最优子结构**：大问题的最优解包含小问题的最优解
- **状态压缩**：如果只依赖前几个状态，可以用变量代替数组

## 示例
```typescript
// 爬楼梯：每次可以爬 1 或 2 个台阶
// dp[i] = dp[i-1] + dp[i-2]
// dp[0]=1, dp[1]=1, dp[2]=2, dp[3]=3, dp[4]=5
```

## 空间优化
```typescript
// 如果只依赖前两个状态
let prev2 = 1;  // dp[i-2]
let prev1 = 1;  // dp[i-1]

for (let i = 2; i <= n; i++) {
  const curr = prev1 + prev2;
  prev2 = prev1;
  prev1 = curr;
}
```
